# Contributing

Issues are welcome: bugs, confusing errors, an engine export the CLI gets wrong, a skill that
teaches the wrong thing. Include the command you ran, the CLI version (`opengame version`) and
what it printed.

This repository is copied from OpenGame's own monorepo at each release, so a pull request
cannot be merged here directly. We read every one, and when we take a change we copy it into
the monorepo with credit to you, and it arrives here in the next release.

By opening a pull request you agree that your change is licensed under this repository's
[Apache 2.0 license](LICENSE).
