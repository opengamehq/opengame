# Security

Email **team@opengame.io** with what you found, how to reproduce it and what it lets someone
do. Please do not open a public issue for a vulnerability.

This covers the code in this repository and the services it talks to: opengame.io, the API
under `opengame.io/api/v1`, and games served from `opengame.gg`.

Games on OpenGame are written by other people and run in a sandbox on `opengame.gg`. A game
that can reach anything outside its own frame on `opengame.gg`, read another game's data, or
reach `opengame.io` as the player is a vulnerability, and we want to hear about it.
