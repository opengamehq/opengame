# opengame-assets changelog

## 1.1.0

Adds what Last Contact (LC), OG Snipers (OS) and OG Hero (OH) taught about sourcing assets:
prove one route end to end before a batch, buying tools that run dry by default, artists'
models for what the player holds with generation kept to bodies, far props and variety, a
studio render beside a real photograph as the gate, grading every generated or scanned
material, licences on file for every asset, generated photographs used for composition
only, and git that never rewrites a binary file. The rigging rule now keeps the exact
mesh a paid rig was made on and points to `opengame-characters` for ordering and re-baking
generated people.

## 1.0.0

First public release, in the opengamehq/opengame repository and the OpenGame CLI.
