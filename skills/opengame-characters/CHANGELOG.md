# opengame-characters changelog

## 1.1.0

The player's OG is drawn from the SDK alone: `readAvatar`, `portraitUrl` for the head as
OpenGame draws it, the style spec in `AVATAR-SPEC.md` and the Three.js example in
`examples/avatar-threejs`. The unpublished character kit is gone from the skill.

## 1.0.1

Tighter rules on sending a player's OG to anybody else.

## 1.0.0

First public release, in the opengamehq/opengame repository and the OpenGame CLI.
