# opengame-front-end changelog

## 1.1.0

Menus stand on a sharp still, a film proven smooth or a live scene measured at the play floor, replacing "every menu is a live scene" (OS). New rules from LC, OS and OH cover menu effects that never move the interface, console-grade input, interface time on the wall clock, the press that starts play, text audited at many sizes and settings from one schema.

## 1.0.1

The default name in a first run is the signed-in player's handle on OpenGame, and the game's own default name otherwise.

## 1.0.0

First public release, in the opengamehq/opengame repository and the OpenGame CLI.
