# opengame-loading changelog

## 1.1.0

New rules for a first frame that needs no fetch (OH), cold visits measured with an empty driver shader cache and fewer request waves (OS), a menu that answers the moment it shows (LC), the lobby as the loading screen (OS) and textures decoded off the main thread and shipped by role (LC). The count now reads 100 only when play can start, budgets only fall, and a new helper, `loading-count.mjs`, does the counting.

## 1.0.0

First public release, in the opengamehq/opengame repository and the OpenGame CLI.
