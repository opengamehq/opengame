# opengame-mobile changelog

## 1.1.0

The capability rule now covers missing WebGL 2 and touch-only phones opening a game without touch, so no visitor meets a blank page or a dead prompt (OH, OS, LC). CPU copies are freed only where nothing re-reads them (OS), and tier, memory and frame-rate rules gain OS's lessons on whole-tab memory, forced tiers that never reached the engine, and counting presented frames.

## 1.0.0

First public release, in the opengamehq/opengame repository and the OpenGame CLI.
