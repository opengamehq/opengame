# opengame-montage-make changelog

## 1.0.0

First public release: build a gameplay montage from its plan at any capture tier, with relay and bounded waits for the agent team, film-build hooks or replay passes, takes as code on the beat grid, payoff cinematics from the same run, offline take checks and a resumable cut chain that delivers read back. Built from the OG Snipers montage.
