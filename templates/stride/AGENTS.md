# Working on stride

Read README.md and the Engines page in the OpenGame docs (`/engines/overview`) before changing this starter. Use the SDK this starter already depends on, from `packages/sdk` in the OpenGame repository. Keep provider keys and account credentials out of the project and its build.

Build real source with the named toolchain. Never create empty wasm, copied screenshots or a placeholder index page to stand in for an engine export. Report missing tools or licences as prerequisites. A local check passing does not mean the game has been tested on OpenGame's servers yet. Deploy it and play the private preview before telling the creator it works.

Submit only when the creator asks. The creator then certifies the submission in their own browser; you cannot do that step. Keep `.opengame/` so retries use the existing game and release.
